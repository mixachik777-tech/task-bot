# Как работать с ботом задач (после перехода на бота-без-чата)

Гид для команды редакции. Всё происходит в личке с ботом — отдельного группового чата для задач больше нет.

## Главное меню

Открой переписку с ботом. Внизу клавиатура с кнопками. У всех ролей:

- ➕ Создать задачу — любой активный участник может поставить задачу
- 👤 Кабинет — твои активные задачи, продуктивность, открытие карточки прямо в боте
- 📁 Архив — закрытые и отменённые задачи с поиском и фильтрами
- 👥 Состав — список участников редакции по направлениям
- 🤖 Спросить AI — справочный помощник по задачам

У руководителя и админа добавляется ещё:

- 📊 Статистика — сводная аналитика по команде, продуктивность по людям

Если кнопок «Кабинет», «Создать задачу» или «Статистика» нет — нажми /start, бот пришлёт сообщение со свежей клавиатурой.

## Постановка задачи

Жмёшь «➕ Создать задачу», мастер ведёт по шагам:

1. Направление — корректоры, дизайнеры или корреспонденты. Карточка задачи уйдёт в личку всем активным участникам выбранного направления (кроме тебя).
2. Название — короткий заголовок, 5–255 символов.
3. Важность — низкая, средняя, высокая, срочная.
4. Срок — пишешь человеческим языком: «завтра 18:00», «через 2 часа», «15.05 14:00».
5. Описание — что именно нужно сделать. Для дизайнеров вместо одного поля три структурированных: назначение, формат, референс.
6. Файлы — можно приложить документ, фото, видео, до 20 МБ каждый.

После «✅ Отправить» бот:

- рассылает карточку каждому активному участнику направления в их личку;
- тебе в личку приходит сводка «отправлено N, не доставлено M», список не доставленных бывает если человек не нажимал у бота /start.

## Приём задачи в работу

Когда тебе в личку прилетела карточка задачи, ты видишь там название, важность, срок, описание, файлы, кнопку «✋ Принять в работу».

- Если жмёшь «Принять» — задача становится твоей, у остальных коллег из этого направления карточка автоматически удаляется из лички. Они получают короткое сообщение «задачу #N уже взял такой-то».
- Постановщик получает уведомление «такой-то взял задачу в работу».
- Если ничего не делаешь — кто-то другой принимает первым, твоя карточка исчезает с экрана.

В принятой задаче кнопки меняются на «✅ Завершить», «💬 Комментарий», «❌ Отменить».

## Завершение задачи

Жмёшь «✅ Завершить». Бот в личке просит описать результат и приложить файлы:

- Шли текст с тем, что сделано.
- Прикрепляй файлы — документ, фото, видео. Можно несколько сообщений подряд, всё копится в одном отчёте. Лимит — 10 вложений, 1000 символов комментария.
- Подпись к файлу автоматически уходит в комментарий.
- Когда всё готово — «✅ Готово, завершить». Если нужно без отчёта — «Без отчёта». Передумал — «❌ Отмена».

После «Готово» задача переходит в статус «На согласовании». Бот не закрывает её сразу — отправляет постановщику в личку всё, что ты приложил (текст + файлы) и две кнопки.

## Согласование результата (для постановщика)

В личку прилетает отчёт исполнителя — заголовок, твой комментарий (если он его писал), все файлы. На последнем сообщении две кнопки:

- ✅ Согласовано — задача закрывается. Исполнителю приходит «спасибо, согласовал».
- ✏️ На доработку — открывается мастер возврата задачи. Здесь обязательно напиши, что именно нужно поправить (это уйдёт исполнителю), можно дополнительно приложить файл-референс. Без текста с правками отправить нельзя — иначе исполнитель не поймёт что не так. По «✅ Отправить на доработку» задача возвращается ему в работу с твоими правками.

Доработок может быть сколько угодно. История всех итераций видна в карточке задачи.

## Кабинет

«👤 Кабинет» — единая точка для исполнителя. Показывает:

- Циферки продуктивности за сегодня/неделю/месяц (назначено, выполнено, в работе, просрочено, в срок, среднее время выполнения).
- Активные задачи разложены по «температуре» дедлайна — просрочено / горит ≤24 часов / сегодня / на неделе / позже.
- Залипшие — задачи в работе без движения дольше недели.

Под сводкой кнопки:

- 🔎 Открыть карточку — открывает список твоих активных задач кнопками. Жмёшь на любую — карточка задачи открывается прямо в боте, оттуда же можно «Завершить», «Комментарий», «Отменить» без поиска по чату.
- 🎯 Свободные задачи — список задач без исполнителя по всем направлениям. Брать их нужно у себя в личке (если ты входишь в нужное направление и карточка к тебе пришла), не из кабинета.
- 🔄 Обновить — пересобрать кабинет с актуальными данными.

Если ты сам поставил задачу и её ещё никто не принял, она тоже видна в твоём списке через «🔎 Открыть карточку» с пометкой 🆕.

## Архив

«📁 Архив» — закрытые и отменённые задачи. Открывается списком с фильтрами по направлению, статусу, периоду, исполнителю. Клик по задаче — полная карточка плюс лента истории (кто что когда делал). Всё работает в боте, никуда не уводит.

## AI-помощник

«🤖 Спросить AI» — справочный помощник по задачам. Что умеет:

- Поиск твоих задач: «мои просрочки», «что у меня в работе», «найди задачи про афишу».
- Сводки и нагрузка: «сколько у команды за неделю» (для руководителей), «нагрузка Алёны за месяц».
- Карточка и история: «покажи задачу #15», «история задачи про корректуру».
- Поиск людей: «найди Вику», «кто из корректоров активен».
- Помощь в формулировке: «сформулируй задачу: афиша 9 мая на корректуру» — даст черновик из четырёх строк (название, описание, важность, срок), создавать саму задачу нужно потом через «➕ Создать задачу».

Чего AI не делает: не создаёт и не меняет задачи, не отвечает на вопросы вне темы редакции, не генерирует картинки.

Лимит — 1000 символов на вопрос и личная дневная квота. Подробнее в `docs/AI_AGENT_GUIDE.md`.

## Уведомления и напоминания

- Напоминания о приближающемся дедлайне приходят в личку: за двое суток, за сутки, за два часа.
- Если дедлайн прошёл, а задача не закрыта — приходит уведомление о просрочке.
- Когда задача отправлена на согласование, напоминания исполнителю снимаются. Если постановщик возвращает на доработку — возвращаются снова.

## Что делать если

- «У меня нет кнопки `Создать задачу` / `Кабинет`» — нажми /start у бота, клавиатура обновится.
- «Я не получаю карточки задач» — проверь не заблокирован ли бот, не нажимал ли когда-то «остановить». Зайди в переписку и нажми /start.
- «Карточка пропала с экрана» — её взял в работу кто-то из коллег. Это нормально, не баг.
- «Поставил задачу — у меня в кабинете её не вижу» — открой «🔎 Открыть карточку», поставленные задачи там с пометкой 🆕.
- «Получил «На доработку» без объяснений» — это невозможно по новой логике, постановщик обязан писать что поправить. Если такое случилось — сообщи админу, это баг.
